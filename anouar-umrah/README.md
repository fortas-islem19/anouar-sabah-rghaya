# صفحة حجز العمرة – أنوار الصباح للسياحة والأسفار (فرع الرغاية)

مشروع React (Vite) لصفحة هبوط واحدة: بانر إعلاني، العروض، آراء المعتمرين (فيديو وصوت)، واستمارة حجز.

## التشغيل

```bash
npm install
npm run dev      # للتطوير على http://localhost:5173
npm run build    # نسخة النشر في مجلد dist/
```

ارفع محتوى مجلد `dist/` على أي استضافة (Netlify، Vercel، Hostinger، cPanel...).

## أين أعدّل؟

| ما تريد تغييره | الملف |
|---|---|
| الهواتف، العنوان، رقم واتساب، روابط فايسبوك/انستغرام/تيك توك | `src/data/agency.js` |
| العروض والأسعار والفنادق وتواريخ الانطلاق | `src/data/offers.js` |
| فيديوهات وتسجيلات المعتمرين | `src/data/testimonials.js` + ملفات في `public/media/` |
| الألوان والتصميم | `src/styles.css` (المتغيرات في أعلى الملف) |
| الصور والملصقات والشعار | `public/images/` |

## إضافة آراء المعتمرين

1. ضع الملفات في `public/media/` (مثلاً `video-1.mp4` و`video-1.jpg` و`audio-1.mp3`).
2. في `src/data/testimonials.js` اكتب المسار والاسم:
   ```js
   { id: 'v1', name: 'الحاج محمد', trip: 'عمرة 19 يوم – أكتوبر', src: './media/video-1.mp4', poster: './media/video-1.jpg' }
   ```
   أو استعمل فيديو يوتيوب: `youtubeId: 'XXXXXXXXXXX'`.
   أو فيديو من **فيسبوك** مباشرة (فيديو أو ريلز منشور على صفحة الوكالة):
   ```js
   { id: 'v1', name: 'الحاج محمد', trip: 'عمرة 19 يوم', facebook: 'https://www.facebook.com/reel/1234567890' }
   ```
   للحصول على الرابط: افتح الفيديو على فيسبوك ← **مشاركة ← نسخ الرابط**. يجب أن يكون المنشور **عاماً (Public)**،
   ويُفضّل الرابط الكامل الذي يبدأ بـ `https://www.facebook.com/...` بدل الروابط المختصرة `fb.watch`.
3. البطاقات الفارغة تظهر كـ «قريباً» إلى أن تضيف الشهادة.

> يُفضّل أخذ موافقة المعتمر قبل نشر صوته أو صورته.

## كيف تصل الحجوزات؟

- عند تأكيد الاستمارة يُفتح **واتساب** برسالة جاهزة فيها كل معلومات الحجز، تُرسل إلى الرقم `whatsapp` في `agency.js`.
- اختياري: تُحفظ الحجوزات أيضاً في **Google Sheets** (انظر القسم التالي).

## ربط الاستمارة بـ Google Sheets

1. أنشئ جدولاً جديداً على [Google Sheets](https://sheets.new).
2. من القائمة: **Extensions (الإضافات) ← Apps Script**.
3. احذف الكود الموجود والصق محتوى الملف `google-apps-script/Code.gs`، ثم احفظ.
4. **Deploy ← New deployment**، اختر النوع **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   ثم اضغط Deploy ووافق على الصلاحيات.
5. انسخ رابط **Web app URL** (ينتهي بـ `/exec`) وضعه في `bookingEndpoint` داخل `src/data/agency.js`.
6. أعد البناء `npm run build` وانشر.

كل حجز جديد يُضاف كسطر في ورقة «الحجوزات»، وتُنشأ عناوين الأعمدة تلقائياً.

**للتأكد أن الربط يعمل:**
- افتح رابط Web app في نافذة خاصة: يجب أن تظهر رسالة `OK – متصل بالجدول...`. إذا ظهرت صفحة تسجيل دخول فإعداد «Who has access» ليس **Anyone**.
- من محرّر Apps Script اختر الدالة `testInsert` واضغط **Run**: يجب أن يظهر سطر «TEST» في الجدول.
- إذا استعملت جدولاً آخر، غيّر `SPREADSHEET_ID` في أعلى الكود.
عند تعديل الكود لاحقاً: **Deploy ← Manage deployments ← Edit ← New version** ليبقى نفس الرابط.
